# Marten releases

Builds of Marten for Mac, a media player and library for your own add-ons and files.

Marten is in beta: the basics should work well, but expect problems. It is free, signed and notarised by Apple, and needs macOS 15 or later.

This repository holds only the release files; the app's source is not here. Download from [getmarten.app/download](https://getmarten.app/download). The app updates itself from here, and asks before it installs an update.

Notices for the open-source libraries Marten is built with: [getmarten.app/licences](https://getmarten.app/licences). A problem or an idea: Report a problem in Marten's Settings, or support@getmarten.app.
